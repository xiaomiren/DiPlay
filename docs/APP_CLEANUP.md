# 应用清理

设置 → 应用清理列出具有桌面启动图标的应用，以及此前由此入口停用的应用。
不会扫描并猜测哪些厂商服务可以删除。

- 应用详情／存储：打开 Android 的应用管理页面，由系统提供清缓存等能力。
- 普通应用卸载：打开 Android 卸载确认页面。
- 停用：通过用户授权的本机网络 ADB 执行 `pm disable-user`，仅作用于当前用户。
- 恢复：通过 ADB 执行 `pm default-state`，恢复默认启用状态。

本机 ADB 沿用项目现有 `127.0.0.1:5555` 协议，不支持 Android 11 的 TLS 无线调试配对。
不能连接 ADB 时仍可使用应用详情和普通卸载入口。

每次停用／恢复均需要用户确认。DiPlay 自身、系统 UID 应用、persistent 应用、
Android 设置、当前默认桌面和输入法不提供停用入口。保护规则无法识别所有厂商
车控、CAN、倒车影像依赖；未知应用应保留，仅在停车后操作。

停用不会删除系统分区 APK，也不承诺释放它们占用的空间。不包含 root、系统分区
修改或自动批量清理。在应用私有设置中保存恢复列表，不保存 ADB 命令输出。
卸载 DiPlay 或清除其数据会失去该列表，所以应先恢复所选应用。

尚需真实 RK3326 / Android 11 车机验证 ADB 可用性和厂商停用限制。
